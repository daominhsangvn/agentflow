## 2026-11-01

Self-hosted edition as it stands.

- Projects connect to Jira, Confluence, Bitbucket, Local Git and other integrations through project connections and connection grants.
- Orchestrated workflows: an Orchestrator Agent follows rules written in plain language and starts tasks for Agents.
- Projects belong to the organization; teams are gone.
- Workflows show case counts. Cases have a run-style list and detail page.
- Task guards refuse undeclared commands, write tasks of read commands and writes from a superseded turn. Refused calls show on the case.
- Agents report their Claude Code version, and personal Agents get the `claude install` command when it differs from the pinned one.
- Blockers: `source_item_get` returns `blockedBy` / `blocks` from Jira "Blocks" links and Azure DevOps Dependency relations. The new orchestrator tool `case_notify` leaves a "Case notice" on another case of the workflow and wakes it, so a waiting case can continue when its blocker is done.
- New setup guide for orchestrated workflows, with the LeaveDesk example.
- New navigation: Home, Cases, Runs, Sessions, Workflows, Agents and Connections. Projects have the tabs Overview, Workflows & Cases, Agents, Connections & Repos and Instructions.
