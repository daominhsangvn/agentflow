## Server

| Symptom | Cause | Fix |
|---|---|---|
| `P1001: Can't reach database server at undefined:5432` | `DATABASE_URL` is not set or Docker is not running. | Run `docker compose ps`. Check `packages/database/.env` and the `.env.local` of each app. |
| `Cannot find module '@repo/database'` | The Prisma client is not generated. | Run `pnpm --filter @repo/database db:generate`. |
| Environment variable validation failed | A variable is missing or invalid. | Add it to `.env.local`. An empty `""` fails validation: comment out unused variables instead. See [Server environment variables](/docs/reference/server-env). |
| Attachments fail to upload or transcripts do not load | Buckets or CORS rules are missing on RustFS. | Run `pnpm storage:init`, and again after changing the app's origin. |

## Agents

| Symptom | Cause | Fix |
|---|---|---|
| Agent exits with code 2 and `Invalid configuration: ...` | A variable is missing or invalid; the message names it. | Fix the variable. See [Agent CLI](/docs/reference/agent-cli). |
| `AGENTFLOW_API_URL: Origin must use https ...` | The Agent reaches the API over plain http on a non-local host. | Use https, or list the host in `AGENTFLOW_ALLOW_HTTP_HOSTS`. |
| Agent exits with code 3 and `Cannot start: missing required tools ...` | `bash`, `git`, `claude`, `jq` or `python3` is not on the PATH, the plugins are not found, or the workspace is not writable. | Install the missing tool or fix the workspace path. |
| `Connection degraded: ...` | The API is unreachable or rejects the key (revoked, or missing `write` scope). The Agent keeps retrying. | Check the API URL and issue a new key. |
| Agent shows offline | The Agent stopped or lost its connection. | Look at Needs attention on Home and at the [Agents page](/docs/guides/operate/agents), then restart the Agent. |
| Task fails with a `claude install <version>` message | A personal Agent's Claude Code version differs from the pinned version. | Run the command shown on the machine. |
| `No Claude credentials on this runner` warning | Expected when a Model provider is set in AgentFlow. Otherwise tasks fail at the first `claude` call. | Set the Model provider on the Agent, or sign in to Claude Code on the machine. |

## Integrations

| Symptom | Cause | Fix |
|---|---|---|
| Webhooks do not arrive | The server is not reachable over public HTTPS from the integration. | Expose the API on a public HTTPS URL, or use polling where the trigger supports it. See [Triggers and actions](/docs/guides/setup/triggers-and-actions). |
| A connection test fails | The token expired or lacks scopes. | Update the token in [Connections](/docs/guides/setup/connections) and test again. |
| A task cannot use a connection | The project has no grant for it. | See [Connection grants](/docs/guides/setup/connection-grants). |

## Workflows & cases

| Symptom | Cause | Fix |
|---|---|---|
| A case waits and nothing happens | The case is waiting for a person to answer or approve. | Open the case and read the last message. See [Cases](/docs/guides/operate/cases). |
| A task is blocked | The task finished with an answer starting `BLOCKED:` because a file or page its command needs is missing. | Pass the file or page in `files`, or produce it first. See [Blocked tasks](/docs/guides/recipes/blocked-tasks). |
| A tool call shows as "Refused" | A guard refused it (undeclared command, missing `needs`, superseded turn). | Fix the rules or the capabilities. See [Orchestrator rules](/docs/guides/recipes/orchestrator-rules). |
| No workflow starts on a ticket change | The trigger does not match or the workflow is disabled. | Check the workflow YAML. See [Workflow YAML](/docs/guides/setup/workflow-yaml). |
