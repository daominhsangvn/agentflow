These pages describe the screens you use once AgentFlow is set up. Each one is in the app's sidebar.

| Page | Sidebar location | What it is for |
|---|---|---|
| [Home](/docs/guides/operate/home) | **Home** | Counts for the organization and a **Needs attention** list |
| [Cases](/docs/guides/operate/cases) | **Cases** (Work) | Tickets handled by an Orchestrator Agent: conversation, tasks, decisions, documents |
| [Runs](/docs/guides/operate/runs) | **Runs** (Work) | Runs of workflows that are not orchestrated |
| [Agents](/docs/guides/operate/agents) | **Agents** (Setup) | Every Agent with its health and Claude Code version |
| [Sessions](/docs/guides/operate/sessions) | **Sessions** (Work) | Claude Code sessions the Agents report, with tokens and cost |
| [Email notifications](/docs/guides/operate/notifications) | A workflow action | Email people when a run needs input or ends |

A project's own view is under **Projects**: the project page has the tabs Overview, Workflows & Cases, Agents, Connections & Repos and Instructions.
