---

Each recipe is a pattern for the plain-language rules of an [orchestrated workflow](/docs/guides/setup/orchestrator), with the rule text that worked on LD-6 and what the platform enforces whatever the rules say.

| Recipe | Use it to |
|---|---|
| [Writing orchestrator rules](/docs/guides/recipes/orchestrator-rules) | Structure the rules and phrase each part |
| [Files and Confluence pages](/docs/guides/recipes/files-and-pages) | Hand files to tasks, publish and update pages, keep people's edits |
| [Status flows](/docs/guides/recipes/status-flows) | Tie work to ticket statuses, absorb quick flips, handle a status you come back to |
| [Questions and answers](/docs/guides/recipes/questions-and-answers) | Post questions, take answers by reply, resume when all are answered |
| [Blocked tasks](/docs/guides/recipes/blocked-tasks) | React to a task that could not start |
| [Waiting for blockers](/docs/guides/recipes/waiting-for-blockers) | Hold work until the tickets that block it are done, and wake the waiting case |
| [Cancelling](/docs/guides/recipes/cancelling) | Stop tasks when the ticket moves backward |

The full rule text is in the [LeaveDesk example](/docs/guides/setup/leavedesk-example).
