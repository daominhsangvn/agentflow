title: "Getting started"
description: "Five steps from an empty server to a Jira comment answered by the Orchestrator Agent."
---

Install the server, create the first admin, start an Agent and run one orchestrated workflow on a Jira ticket. Do the steps in order: each one uses what the one before it created.

| # | Step | What you do |
|---|---|---|
| 1 | [Prerequisites](/docs/getting-started/prerequisites) | Check the machine, the URLs, the Claude credentials and the bot accounts you need |
| 2 | [Install the server](/docs/getting-started/install-server) | Start Postgres, RustFS, Mailpit and Local Git with Docker, then the app, API and MCP server |
| 3 | [First admin and organization](/docs/getting-started/first-admin) | Sign up, create a project and an API key for Agents |
| 4 | [Install an Agent](/docs/getting-started/install-agent) | Start an automatic Agent (Docker) or a personal Agent and set its model provider |
| 5 | [Quickstart](/docs/getting-started/quickstart) | Connect Jira, write a small orchestrated workflow and mention the bot on a ticket |

At the end, a comment on a Jira ticket is answered by the Orchestrator Agent in the same thread, and the ticket shows up as a case under **Cases** in the sidebar.

For a complete, real setup (four repositories, four Agents and the rules for one ticket from To Do to Done), read the [LeaveDesk example](/docs/guides/setup/leavedesk-example) after the quickstart.
